# prompts/README.md

這個資料夾不是程式 runtime 依賴，而是 DRCYJ SaaS 的「情境式定錨 Prompt Pack」。

原則：

- 永久規則不要每次重貼，放在 `../PROJECT_OPERATING_RULES.md`。
- 新對話只貼最短 bootstrap。
- 特殊情況再使用對應 prompt。
- 所有 prompt 都要求最後回到「最新正式 source」做 Source of Truth。

建議最常用的只有三個：

```text
01_NEW_CHAT_BOOTSTRAP.md
02_REANCHOR_MID_CHAT.md
03_CONTEXT_LIMIT_HANDOFF.md
```

其餘是事故／交接／外部修改時再使用。
